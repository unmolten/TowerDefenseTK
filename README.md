# 🏰 Tower Defense TK

¡Bienvenido a **Tower Defense TK**! Un juego de estrategia desarrollado en Python. Defiende tu base utilizando diferentes tipos de torres y muros, elige tu facción y sobrevive a las oleadas de enemigos.

## ⚙️ Requisitos Previos

Necesitas tener instalado **Python 3.x** en tu computadora. Puedes descargarlo en [python.org](https://www.python.org/).

---

## 🚀 Instrucciones de Instalación

1. **Clona o descarga el proyecto:**
   Descarga el código fuente y guárdalo en una carpeta en tu computadora.

2. **Instala las dependencias:**
   Abre tu terminal (o CMD) dentro de la carpeta del proyecto y ejecuta:
   ```bash
   pip install pygame
   ```
3. **Corre el juego:**
   ```bash
   python Main.py
   ```
